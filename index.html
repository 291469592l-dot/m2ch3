3.1

弧度制 Radian Measure

pp. 3.2 – 3.7 ｜ Exercise 3A

本节定位

把「角度」从人为规定的 360 等分换成几何自然量——弧长与半径之比。之所以整章必须用弧度，是因为后面所有公式（尤其微分、积分与级数）都只在弧度制下成立。本节只有两个核心产出：一个定义（θ = ℓ/r）与一条换算关系（180° = π rad）。

A · 弧度的定义

圆心角 θ 所对的弧长为 ℓ、半径为 r。若弧长恰好等于半径（ℓ = r），则该圆心角的大小定义为 1 弧度（1 rad，也可写作 1c）。

核心公式 θ = ℓr rad

推导只用到初中知识「弧长与圆心角成正比」：

θ1 rad = 弧长 BC弧长 AB = ℓr ⟹ θ = ℓr rad
关键理解弧度是「长度 ÷ 长度」，是一个纯数（无量纲）。所以 sin θ、θ 本身可以相加、相乘，也能直接放进微积分公式；写成 sin θ 中的 θ 本质上没有单位。这就是为什么「1 rad 有时省略单位写作 θ = 1」。

B · 度与弧度的换算

取半圆：θ = 180°，弧长 ℓ = 12(2πr) = πr，代入 θ = ℓ/r 得 θ = π rad。

换算基准 180° = π rad 1° = π180 rad ≈ 0.0175 rad　（度 → 弧度：× π180） 1 rad = 180π° ≈ 57.3°　（弧度 → 度：× 180π）

本节例题（含答案要点）

例 1度 → 弧度（p.3.4）Level 1乘以 π/180

把 60°、90°、315° 化为弧度，答案以 π 表示。

60° = 60 × π180 = π3 rad 90° = 90 × π180 = π2 rad 315° = 315 × π180 = 7π4 rad

套路：度 → 弧度，唯一动作就是「× π/180」，然后约分。315 = 45 × 7，180 = 45 × 4，所以直接得 7π/4——先约分再乘 π 更快。

例 2弧度 → 度（p.3.5）Level 1乘以 180/π

把 π4 rad 与 1.5 rad 化为度（必要时取 3 位有效数字）。

π4 rad = π4 × 180°π = 45°　（快法：直接把 π rad 换成 180°） 1.5 rad = 1.5 × 180°π ≈ 85.9°（3 位有效数字）
两种写法含 π 的答案用「替换法」最省事（π rad = 180°）；纯小数则必须保留 π 在分母并用计算器，注意有效数字要求（此章多为 3 sig. fig.）。

本节陷阱

Do's and Don'ts
  • 扇形角度公式用弧长比直径：θ = ℓ/r，其中 r 是半径不是直径。用直径算出的答案会小一半。
  • 度与弧度混用：写 sin 30 与 sin 30° 是完全不同的值；本章后半段一律用弧度，题目给度数时请先转换。
  • 计算器未切 RAD 模式：CASIO fx-50FH II 需按 SHIFT → MODE → 2（PROG/RAD 显示「R」）。3.2 节的计算器题型出错几乎都源于此。
  • 漏写单位 rad / 漏写 °：HKDSE 会因单位缺失扣分。

3.2

六个三角函数 The Six Trigonometric Functions

pp. 3.8 – 3.20 ｜ Exercise 3B

本节定位

把函数族从 3 个扩到 6 个：新增 cosec（餘割）、sec（正割）、cot（餘切），它们分别是 sin、cos、tan 的倒数。这三个函数不是「多背三个公式」而已——它们是复角公式、二倍角公式证明题的常客，也是 DSE 长题变换的主要对象。本节还要解决两件事：象限符号判定（CAST）与含 cosec/sec/cot 的三角方程。

A · 定义（任意角的六个比值）

设 P(x, y) 为角 θ 终边上任一点，r = OP = √(x2 + y2) > 0。

函数sin θcos θtan θcosec θsec θcot θ
定义 y / rx / ry / x r / yr / xx / y
限制 ——x ≠ 0 y ≠ 0（即 sin θ ≠ 0）x ≠ 0（即 cos θ ≠ 0）y ≠ 0（即 sin θ ≠ 0）
倒数关系（3.3 节将正式命名） cosec θ = 1sin θ　　sec θ = 1cos θ　　cot θ = 1tan θ = cos θsin θ
Do's and Don'ts（教材 p.3.8 明示） sec θ ≠ 1sin θ　　cosec θ ≠ 1cos θ
最稳的记法：cosec 是 sin 的倒数，sec 是 cos 的倒数，cot 是 tan 的倒数；其中 sec 与 cos 只差一个首字母（s ↔ c），必须硬记，而 cosec 与 cos 的搭配没有字面线索 —— 「sec = 1/cos」是本卷最高频的低级错误来源。
术语cosec 也写作 csc（部分教材／计算器）。六个函数统称 trigonometric functions（三角函数）；cosec θ、sec θ、cot θ 分别称为 cosecant / secant / cotangent function。

C · 符号与 CAST 图

象限正值的函数
I全部为正（All）

本质推导：r > 0 恒成立，符号完全由 x、y 的符号决定：

  • sin = y/r、cosec = r/y → 随 y 变号
  • cos = x/r、sec = r/x → 随 x 变号
  • tan = y/x、cot = x/y → 同号为正、异号为负
进阶记法CAST 图的字母按逆时针从第四象限开始读 C→A→S→T，对应「Cos positive、All positive、Sin positive、Tan positive」。而 3.3 节的「奇变偶不变，符号看象限」中的「符号」就是查这张图。

E · 解含 cosec / sec / cot 的三角方程（两步法）

标准流程 Step 1　用倒数关系把方程化回 sin x / cos x / tan x Step 2　求参考角 a，再按所求区间写出全部满足的 x
参考角（reference angle）：先解 sin a = |k| 之类的锐角 a，再用 CAST 图把 a 投射到正确象限。例如 tan x = −1/√3，a = 30°，tan 在 II、IV 为正？不——tan 在 II、IV 为负，故 x = 180° − 30° = 150° 或 360° − 30° = 330°。

本节例题（拆解 + 答案要点）

例 3由坐标求六个函数值（p.3.9）L1

已知 P(−4, 3) 在 θ 终边上，求六个三角函数值。

r = √((−4)2 + 32) = 5 sin θ = 3/5　cos θ = −4/5　tan θ = −3/4 cosec θ = 5/3　sec θ = −5/4　cot θ = −4/3

套路：三步固定 —— ① 算 r（必为正）；② 直写 sin/cos/tan；③ 逐个取倒数。注意 cot θ = 1/tan θ = x/y = −4/3，与 tan 同号。

例 4由符号判定象限（p.3.13）L1

(a) sec θ < 0 且 cosec θ < 0；(b) cosec θ > 0 且 cot θ < 0。

(a) sec<0 ⇒ II 或 III；cosec<0 ⇒ III 或 IV　⟹　θ 在 第 III 象限 (b) cosec>0 ⇒ I 或 II；cot<0 ⇒ II 或 IV　⟹　θ 在 第 II 象限

套路：每个条件给出「两个候选象限」，取交集。若交集为空 ⇒ 该角不存在（Level 2 会出现这类「无解」判断题）。做题时建议在草稿纸上画出两个条件各自覆盖的扇区。

例 5由一函数值求其余值（唯一象限）（p.3.13）L1

已知 cot θ = −√3，且 π < θ < 2π，不用计算器求 sec θ 与 cosec θ。

cot θ < 0 且 π < θ < 2π ⇒ θ 在第 IV 象限 取 x = √3, y = −1 ⇒ r = √(3 + 1) = 2 sec θ = r/x = 2/√3 = 2√33　　cosec θ = r/y = 2/(−1) = −2
为什么可以「自己选 x、y」三角函数只依赖比值，所以在终边上任取一点都成立。选最简单的整数点（√3, −1）比硬算更方便。唯一约束是 x、y 的符号必须符合所在象限、且 r 要算对（r 一定为正）。
例 6同一比值、两个象限 ⇒ 两组答案（p.3.14）L2

已知 sec θ = −5/3，0 ≤ θ ≤ 2π，求 cosec θ 与 cot θ。

sec θ < 0 ⇒ θ 在 II 或 III 象限 ⇒ 必须分两种情况 取 x = −3, r = 5 ⇒ y2 = 25 − 9 = 16 ⇒ y = ±4 QII（y = 4）：cosec θ = 5/4，cot θ = −3/4 QIII（y = −4）：cosec θ = −5/4，cot θ = 3/4
评分点「两组答案」是本节最典型的失分点：题目给的是 0 ≤ θ ≤ 2π 这种「跨象限区间」时，一定要写出两组并分别说明象限；只写一组直接扣一半分。
例 7解方程（度数，含多倍角）（p.3.15）L1

(a) cot x = −√3；(b) sec 2x = √2，其中 0° ≤ x ≤ 360°。

(a) tan x = −1/√3 ⇒ a = 30° ⇒ x = 180° − 30° = 150° 或 360° − 30° = 330° (b) 令 y = 2x，则 0° ≤ y ≤ 720°；cos y = √2/2 ⇒ y = 45°, 315°, 405°, 675° ⟹ x = 22.5°, 157.5°, 202.5°, 337.5°

套路：遇到 2x、3x 这类多倍角，先整体换元 y = 2x，把区间同步放大（×2），解完 y 再除回。漏掉区间放大 ⇒ 解漏一半。

例 8解方程（弧度，含角的平移）（p.3.16）L2

解 cosec(x + π/3) = 2，0 ≤ x ≤ π。

令 y = x + π/3；由 0 ≤ x ≤ π 得 π/3 ≤ y ≤ 4π/3 cosec y = 2 ⇒ sin y = 1/2 ⇒ y = π/6（舍去，不在区间）或 y = π − π/6 = 5π/6 x + π/3 = 5π/6 ⇒ x = π/2
双重检验（教材 p.3.16 明确提示）解出的 x 必须同时满足：① 落在题目给定区间内；② 代回原方程成立。含平移的题，参考角对应的「另一个解」常常落在区间外，必须显式写出「rejected」。
例 9可化为二次方程（p.3.17）L2

解 3sec2x − 7sec x + 2 = 0，0 ≤ x ≤ 2π。

(sec x − 2)(3 sec x − 1) = 0 ⇒ sec x = 2 或 sec x = 1/3 cos x = 1/2 或 cos x = 3（舍去，因 −1 ≤ cos x ≤ 1） x = π/3 或 2π − π/3 = 5π/3

套路：整体把 sec x 当作一个字母 t 做因式分解，最后一定回到 cos（或 sin），并用 −1 ≤ cos x ≤ 1 筛掉不可能的根。这一步是 Level 2 的固定采分点。

3.3

三角恒等式 Trigonometric Identities

pp. 3.20 – 3.30 ｜ Exercise 3C

本节定位

本节是全章的「代数工具箱」：把六函数之间的**恒等关系**系统化，并提供一整套诱导公式（把任意角化简为锐角）。它本身考的不多，但 3.4–3.6 所有证明题的第一步几乎都是「化简」。学不好这一节，后面只能背答案。

A · 三类基本恒等式

① 倒数恒等式 cosec θ = 1sin θ　sec θ = 1cos θ　cot θ = 1tan θ

和积公式 Sum and Product Formulae

pp. 3.47 – 3.57 ｜ Exercise 3F

本节定位

把 3.4 的六条公式「加减」一下，就得到两组互逆公式：积化和差（乘 → 加）与和差化积（加 → 乘）。它们解决的是「次数太高」或「项数太多」的问题，是 DSE M2 长题（6–8 分）的标配工具。本节还引入一个跨主题难点：与数学归纳法联手的求和恒等式（例 31、Exercise 3F 第 30–31 题、HKDSE 2015 Q8）。

A · 积化和差公式（Product-to-sum）

来源（Class Activity 3.3）：把 sin(A+B) 与 sin(A−B) 两式相加、相减。

三条主公式 2 sin A cos B = sin(A + B) + sin(A − B) 2 cos A cos B = cos(A + B) + cos(A − B) 2 sin A sin B = cos(A − B) − cos(A + B)
第 4 条不是新的（教材 p.3.48 特别说明）：2 cos A sin B = sin(A + B) − sin(A − B) 与第一条等价（只是交换了 A、B 的写法）。因此只需背 3 条，遇到 cos A sin B 把两条「对调」即可。第 3 条最易错：右边是 cos(A−B) − cos(A+B)，减号且在后面（因为 cos 是偶函数、和角在余弦里变号）。
记忆口诀「正余相加、余余相加、正正相减且反序」；且左边是 2 倍乘积，右边是两个同名函数之和/差。

B · 和差化积公式（Sum-to-product）

来源：把积化和差反过来用。令 x + y = A、x − y = B，则 x = (A+B)/2、y = (A−B)/2。

四条 sin A + sin B = 2 sinA + B2 cosA − B2 sin A − sin B = 2 cosA + B2 sinA − B2 cos A + cos B = 2 cosA + B2 cosA − B2 cos A − cos B = −2 sinA + B2 sinA − B2　注意前置负号！
四条公式的差异只有一个格子
  • 「和」+ sin → sin · cos（顺序不变）
  • 「差」+ sin → cos · sin（顺序互换）
  • 「和」+ cos → cos · cos
  • 「差」+ cos → −sin · sin（唯一带负号的一条）
判断左边的 A、B 谁大谁小？公式里一律用 (A+B)/2 与 (A−B)/2，不需要先判断大小，只需注意最后一条的负号。

六大解题套路（逐条可操作）

从 31 个例题中提炼

本章的题目看似花样多，实质上只有六类动作。把下面的「触发信号 → 标准动作」练成条件反射，速度与准确率会同时上升。

套路 1给点求值 / 给值求值基础

触发信号：题目给出 P(x, y) 坐标，或给一个三角函数值 + 象限/区间。

  1. 若给坐标：算 r = √(x2+y2)（必正）→ 直写六个比值。
  2. 若给一个值：先判象限（区间 + 该值的符号，取交集）。
  3. 自设最简单的整数点 (x, y) 符合该象限的符号，再算 r。
  4. 若要的是倒数函数，直接取倒数或直接写 r/y、r/x。
  5. 若区间跨两个象限 ⇒ 必须写两组答案（例 6）。
不要用计算器反三角函数——题目要求「without using a calculator」时，用精确值（如 2/3、√3）作答；用计算器不仅错，还会因小数近似被判错。
套路 2化简（Expression → 单一函数）基础

触发信号：「Simplify …」，出现 cot / sec / cosec 混合。

  1. 全部拆成 sin θ 与 cos θ（万能第一步，例 10）。
  2. 约分、通分；看到 1 与三角函数的组合，考虑替换成平方差（例 12）。
  3. 结果若含 1/sin2 型，回写为 cosec²θ 等（题目通常要求「用单一函数表示」）。
  4. 若出现「sin·cos ± cos·sin」结构，直接认出是 sin(A±B)（例 18）。
套路 3证明恒等式（L.H.S. → R.H.S.）核心

触发信号：「Prove that …」。

  1. 只动一边（通常从较复杂的一边出发），结尾写 R.H.S. 并加 ∎ 或 ∴。
  2. 方向选择：从「次数高/角大」的一边化向「次数低/角小」的一边（例 23）。
  3. 常用四招：① 通分；② 全拆 sin/cos；③ 把常数 1 换成平方差；④ 用和积公式把「加」做成「乘」（便于约分）。
  4. 遇到平方混合（如 sin2/cos2 并存），优先降幂到 2A。
  5. 证明中出现 θ ± π/2 等，先用诱导公式全部换成 θ 的函数（例 14、15）。
禁招两边同时变形、把待证结论当已知代入、「移项后消掉」——阅卷一律不给分。
套路 4解三角方程（含多倍角 / 平移 / 二次型）核心

触发信号：「Solve … for 0 ≤ x ≤ 2π」。

  1. 统一：用一个函数表示（必要时用平方恒等式把 sin² 换成 1−cos²）。倒数函数先转成正弦余弦。
  2. 因式分解（二次型）：整体把函数当作字母 t 分解。
  3. 筛根：|sin x| ≤ 1、|cos x| ≤ 1，超出的解写「rejected」。
  4. 换元：遇到 2x、3x 或 x + π/3，令 y = 该整体，区间同步变换，解出 y 后再回代。
  5. 写全解集：先求参考角，再用 CAST 图找出区间内所有解，按大小排列。
  6. 回代检验：把 x 代回原式（尤其含平移和多倍角时），确认无增根。
区间端点0 ≤ x ≤ 2π 与 0 ≤ x < 2π 不同：半开区间不含 2π，别把 2π 写进答案。
套路 5「先证明，再解方程」两问式（DSE 主体）高分

触发信号：(a) Prove that … (b) Hence solve …。—— 本册 9 套真题中 6 套是这个结构。

  1. (a) 的问法往往暗示了「化简方向」：(b) 要解的方程左边通常正是 (a) 要证的左边，所以 (a) 的结论就是 (b) 的第一行。
  2. (b) 必须显式写「由 (a)」→ 代入 → 转化为较简单的方程（通常退化为 sin 2θ = 0 或 cos θ = 1/2）。
  3. 若 (b) 是「Hence evaluate …」，把特殊角代入 (a) 的等式即可，不需要重新推导。
  4. (a) 若要求「prove by mathematical induction」，务必写全五步（例 31），第 ④ 步必须做代数运算。
套路 6配凑角与「猜特殊角」高分

触发信号：要求 tan A 而已知 tan(A+B)；要证 tan(5π/18)·tan(π/3)·tan(7π/18) 之类「长得不像」的等式。

  1. 配凑角：A = (A+B) − B、A = (A−B) + B（例 17）。
  2. 猜特殊角：看题目中常数的和差是否等于特殊角（例 24 中 5π/18 + 7π/18 = 2π/3），再决定代哪个 x。
  3. 比对系数：把待求式与已证式逐项比对，找出「谁是 α 谁是 β」（例 19）。
常见特殊角关系π/12 = π/3 − π/4、5π/12 = π/4 + π/6、π/8 · π/12 等；以及 π/18, 5π/18, 7π/18 三兄弟（来自 tan 3x 题）。
